# Error Log

Every mistake that cost me time goes here. Review this file before each practice session and before the contest.

## How to write an entry
- **What happened:** the symptom (wrong answer, TLE, crash, compile error)
- **Root cause:** the real reason
- **Fix:** what solved it
- **Rule:** one sentence I can check next time
