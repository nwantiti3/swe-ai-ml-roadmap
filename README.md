## 🎯 What is this?

My personal study repo for **competitive programming in C++**, **software engineering**, and **AI/ML engineering**.

Every module follows the same format, so it is easy to study from, practice with, and even record as a course:

| File | Purpose |
|:--|:--|
| 📘 `notes.md` | Clear explanations with small examples and a summary |
| 💻 `examples/` | Runnable `.cpp` files, each tested before commit |
| 🧩 `exercises.md` | Practice problems with a hint ladder (no spoilers up front) |
| 🎬 `script.md` | Spoken-style narration, ready to use as a video script |

## 🧠 How I study

1. 📖 **Learn** the concept from the notes.
2. ✍️ **Try** the exercises alone first (20 to 30 minutes).
3. 💡 **Use hints** one level at a time, never the full solution first.
4. ✅ **Test** every solution on a real judge (Codeforces, AtCoder, CSES).
5. 🐞 **Log** mistakes in `error-log.md`.
6. 🔁 **Review** old topics in mixed problem sets.

<details>
<summary><b>⚙️ Compile and run any example</b></summary>

```bash
g++ -std=c++17 -O2 file.cpp -o out
./out
```

For debugging, add sanitizers:

```bash
g++ -std=c++17 -g -fsanitize=address,undefined -D_GLIBCXX_DEBUG file.cpp -o out
```

</details>

<details>
<summary><b>📐 Contest rules I follow</b></summary>

- Use `long long` whenever a value or product may pass about 2·10⁹.
- Use `'\n'` instead of `endl` for output.
- Write time and space complexity before coding.
- If stuck for 15 minutes, switch problems or ask a teammate.

</details>
