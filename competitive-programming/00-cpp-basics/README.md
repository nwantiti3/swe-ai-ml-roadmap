# Module 00: C++ Basics

Goal: write, compile, test, and debug small C++ programs, and get ready for contest-style problems.

| # | Lesson | Topics | Folder |
|:-:|:--|:--|:--|
| 1 | Structure, I/O, variables | `main`, `cin`/`cout`, types, overflow | [`lesson-01-structure-io-variables`](lesson-01-structure-io-variables/) |
| 2 | Conditions and loops | `if`, `for`, `while`, input patterns, primes | [`lesson-02-conditions-and-loops`](lesson-02-conditions-and-loops/) |
| 3 | Functions, vectors, strings | functions, references, `vector`, `sort`, `string`, `pair` | [`lesson-03-functions-vectors-strings`](lesson-03-functions-vectors-strings/) |
| 4 | Contest toolkit | template, fast I/O, complexity, debugging, stress tests | [`lesson-04-contest-toolkit`](lesson-04-contest-toolkit/) |

Each lesson folder contains `notes.md`, `exercises.md`, `script.md`, and `examples/`.

Study order for each lesson: read the notes, run the examples, solve the exercises alone, then log mistakes in `../../error-log.md`.
